# 内存偏移速查

来源：CE 表 `Wilds.CT` / `新的.CT` 实测整理（2026-11，4399 PC 版）。
地址形式均为“模块基址 + 偏移”，多级指针按从下到上的顺序解引用。

## 角色对象

```
libcocos2d.dll + 0xAAAEEC → +0xB4 → +0x2B8 → +0x2B4 → +0x2E4
```

| 字段 | 偏移 | 类型 | 备注 |
|---|---|---|---|
| 角色/皮肤 | `+0x13C` | 4 Bytes | |
| 等级 | `+0x120` | 4 Bytes | |
| 体型 | `+0x0A0` | 4 Bytes | 不参与结算，改大不踢 |
| 血量 | `+0x258` | 4 Bytes | |
| 血量上限 | `+0x254` | 4 Bytes | |
| 体力 | `+0x25C` | 4 Bytes | |
| 体力上限 | `+0x260` | 4 Bytes | |
| 拾取范围 | `+0x278` | 4 Bytes | |
| 普攻/伤害范围 | `+0x274` | 4 Bytes | 真人局改会被踢 |
| 移动速度 | `+0x26C` | 4 Bytes | |
| 道具数 | `+0x1DC` | 4 Bytes | |
| 道具数上限 | `+0x1E0` | 4 Bytes | |

## 坐标

多一级 `+0x10`：

```
entity + 0x10 → +0x2C  X（Float）
              → +0x30  Y（Float）
```

## 战绩

```
GameLogic.dll + 0xF7248 → +0x8 → +0x14 → +0x84   击杀/战绩
                        → +0x88                  死亡数
                        → +0x8C                  助攻数
```

## 技能卡池

```
角色对象 + 0x3D4 + 0x1C   vector<SSkillPlanConfig> begin
                 + 0x20   end
                 + 0x24   capacity
```

每条 16 字节：`{config*, weight, name1*, name2*}`；`config+4` 为 9 位 CFG ID。

## 弹窗补丁

```
GameLogic.dll + 0x4D02A   call dword ptr [MessageBoxA]
→ add esp,0x10; nop; nop; nop
```

## 说明

以上偏移只在当前版本有效；游戏更新后需要重新定位。数值类字段仅作研究记录，真人局修改会触发服务端校验。
